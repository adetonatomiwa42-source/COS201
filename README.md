# COS 201 
Computer Programming I (Week 3)
This repository contains three Java programs:

1. `SimpleCalculator.java` – performs addition, subtraction, multiplication and division.
2. `AverageCalculator.java` – calculates the average of any positive number of values entered by the user.
3. `ItemCost.java` – calculates the total cost by multiplying quantity by the cost per item.

## Requirements

- Java Development Kit (JDK) installed.
- A terminal/command prompt or a Java IDE such as Visual Studio Code or IntelliJ IDEA.

## How to compile and run

Open a terminal in this project folder.

### 1. SimpleCalculator

Compile:

```bash
javac SimpleCalculator.java
```

Run:

```bash
java SimpleCalculator
```

### 2. AverageCalculator

Compile:

```bash
javac AverageCalculator.java
```

Run:

```bash
java AverageCalculator
```

### 3. ItemCost

Compile:

```bash
javac ItemCost.java
```

Run:

```bash
java ItemCost
```

## Notes

- Enter numbers when prompted.
- The calculator accepts `+`, `-`, `*` and `/`.
- The calculator checks for division by zero.
- The average program accepts any positive number of values.
- The item cost program calculates `quantity × unit cost`.
- These implementations are based on the program names in the assignment submission instructions. If the lecturer supplied more detailed specifications, follow those specifications instead.
